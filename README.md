# Campus Route Finder Using BFS

## Project Overview
This project finds the shortest route between two campus locations using the Breadth-First Search (BFS) algorithm.

## Objective
To find and display the shortest path between a starting point and a destination on a campus map.

## Technologies Used
- Python
- Google Colab
- NetworkX
- Matplotlib
- GitHub

## Algorithm Used
Breadth-First Search (BFS) explores a graph level by level to find a shortest path in an unweighted graph.

## Features
- Represents campus locations as a graph.
- Finds the shortest route between locations.
- Displays the route in the output.
- Visualizes the campus map.
- Highlights the selected route.

## Example
Starting Location: Main Gate

Destination: Lab

Shortest Route: Main Gate -> Library -> Classroom -> Lab

Number of connections: 3

## How to Run
1. Open Google Colab.
2. Upload the Campus_Route_Finder_BFS.ipynb file.
3. Run all code cells.
4. View the shortest route and campus graph.

## Conclusion
This project demonstrates how BFS can find a shortest route between locations in an unweighted graph.
